leyes-mx

La ley mexicana, versionada.

Cada ley federal es un archivo Markdown en git. Cada reforma publicada en el Diario Oficial es un commit, fechado con su publicación. Así, git log, git diff y git blame funcionan sobre la ley.

Leyes

Prueba en tu terminal

$ git clone https://github.com/BEG-lag/leyes-mx $ cd leyes-mx $ git log --oneline -- leyes/cpeum.md $ uv run leyes diff lft 2019-01-01 --stat # ¿quién cambió este párrafo y cuándo? $ git blame leyes/lft.md
